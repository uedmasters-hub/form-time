FORM / TIME screensaver for Windows 10 and 11
=============================================

Install
  1. Extract the zip (right-click > Extract All...). Don't run it from inside the zip.
  2. Double-click install.cmd.
     If Windows says "Windows protected your PC", choose More info > Run anyway.
     (The screensaver isn't code-signed yet.)
  3. Screen Saver Settings opens with FORM / TIME chosen.
     Settings... changes the clock's look (with a live preview); Preview tries it.

  Nothing needs administrator rights. It installs for you only, into
  %LOCALAPPDATA%\Programs\FORM TIME Screensaver

  It uses Microsoft Edge WebView2, which is part of Windows 11 and of
  up-to-date Windows 10. If the clock says it's missing, install the
  Evergreen runtime from https://go.microsoft.com/fwlink/p/?LinkId=2124703

Using it
  - It shows on every monitor, and closes when you move the mouse, click or press a key.
  - Settings...: face (analog or digital), day or night (or match Windows),
    dial and lume colours, movement, size, seconds, shadows & glow, the date,
    and the time zone (blank = this computer's).
  - The clock drifts a little every minute so nothing burns into the screen.
  - It works offline; it never connects to the internet.

Remove
  Double-click uninstall.cmd (here, or in the install folder).
